# 安装与开始使用

[← 返回首页](../README.md)

## 下载适合你的版本

目前提供 **Apple 芯片（M 系列）Mac** 的 DMG 安装包。

点击屏幕左上角的苹果菜单 → **关于本机**。如果「芯片」显示 Apple M 系列，就可以选择 M 芯片安装包。Intel Mac 和 Windows 暂无本仓库提供的安装包。

打开本仓库的 **Releases（版本发布）**，选择最新可用版本，在 **Assets（附件）** 中下载文件名以 `.dmg` 结尾的安装包。

- 内测版本会标为 **Pre-release**，请先阅读该版本的已知问题。
- `Source code (zip)` 和 `Source code (tar.gz)` 是 GitHub 自动生成的介绍文档打包文件，**不是安装包**。
- 具体系统要求以该版本发布说明为准。

## 安装

1. 双击下载的 `.dmg` 文件。
2. 将「像素番茄钟」拖入「应用程序 / Applications」。
3. 从「应用程序」打开「像素番茄钟」。
4. 首次使用，从六颗神秘蛋中选择两颗，确认后等待孵化。
5. 点击「开始陪伴」，跟随应用内教学设置显示方式并开始专注。

## macOS 提示无法验证开发者

内测包可能尚未经过 Apple 公证，因此首次打开时可能出现安全提示。

确认安装包来自本仓库的正式发布附件后，先尝试打开一次，再前往 **系统设置 → 隐私与安全性**，找到对应提示并选择 **仍要打开**。不同 macOS 版本的提示文字可能略有不同。

如果系统明确提示存在恶意软件，或没有提供继续打开的选项，请停止安装并提交问题，附上完整提示。无需关闭 Mac 的全局安全保护。

## 打开后在哪里找到它

- 有刘海的 Mac 可以在屏幕顶部使用刘海模式。
- 没有刘海的 Mac 可以使用桌宠模式。
- 点击菜单栏的小番茄可以找到常用操作。
- 重新从「应用程序」打开应用，可以进入设置。
- 退出入口在设置窗口左侧栏底部。

## 更新

可以在应用帮助页检查更新，下载完成后选择「重启并更新」。如果在线更新连接失败，或希望使用完整安装包，在本仓库 Releases 下载新版 DMG，退出正在运行的像素番茄钟，再把新版拖入「应用程序」替换旧版。

正常替换应用不会主动删除已有宠物和设置。更新前请阅读对应版本说明；不建议手动删除应用的数据目录。
